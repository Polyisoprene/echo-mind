## 二、 四大根治手术（Remediation Specification）

1. **手术 1：将「群友二人转免打扰（`is_in_dyadic_dnd`）」提权至 Tier 2 之前，且 `@/引用` 他人时立即注销跟聊窗口**
   - 当群友 A `@` 或引用群友 B 时，立即从 `self._followup_until` 中删除群友 A 的跟聊窗口（他已转头跟别人说话）；
   - 在 `PerceptualGate.evaluate` 中，在进入 `_check_tier2_continuation` 之前先检查 `is_in_dyadic_dnd`：只要处于 `A ⇄ B` 90 秒二人转互聊保护窗内，除非显式点名回音（Tier 1），否则一律以 `0.12 (群友二人互动中·礼貌不打扰)` 静默旁听！
2. **手术 2：重构群聊跟聊窗口（`_in_followup`）—— 60s 限时 + 第三人插话熔断 + 最多 1 次无点名续杯**
   - 群聊跟聊窗口从 `300s (5分钟)` 缩短为 **`60s`**；
   - **第三人对话熔断（Interleaved Peer Cancellation）**：记录群内上一条非机器人消息的发送者 `last_peer_uid` 与时间 `last_peer_ts`。如果在群友 A 发言前 45 秒内，刚有另一位群友 B（如 `橡皮`）发过言，说明群友 A 正在跟群友 B 对话，立即抑制群友 A 的无条件 `_in_followup`，甚至自动将其二人绑定进 60s 二人转窗口！
   - **禁止无限续杯**：`mark_replied_to` 仅在本次触发属于 **Tier 1（显式 `@`/点名/引用回音）** 时才开启 60s 跟聊窗口；因跟聊窗口（Tier 2）或外围接话（Tier 3）触发的回复**不再续期 `_followup_until`**，彻底斩断无限续杯链！
3. **手术 3：防抖合并批次仅对「直接点名者」开启跟聊，过滤顺嘴搭腔路人**
   - 在 `facade.on_turn_completed` 中：只有当某个 `trigger` 是 `is_at_me / is_called_by_name / is_quoted_me / scene=="private"` 时，才调用 `mark_replied_to`！像 `#3451` 那样顺嘴回一句 `"确实"` 混进防抖批次的路人，绝不再被误开跟聊窗口。
4. **手术 4：在 `PromptComposer` 注入《群聊非点名闭嘴铁律》**
   - 当 `frame.must_reply == False` 时，明确指示大模型：若上下文显示两位群友正在互相讨论游戏/事务而非对你说话，直接结束本轮（不调任何发送工具），保持安静！
