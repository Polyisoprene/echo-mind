# D15 检索基线（关键词 vs 同义改写）

## 方法

`scripts/eval_memory_retrieval.py`：

- 30 条事实（10 条目标 + 20 条干扰）；
- 10 条查询，刻意用与目标事实**几乎不重叠**的措辞（如“工作”对“岗位”、“睡”对“熬夜”）；
- 调 `select_relevant_facts(..., limit=5)`，统计目标是否进 top-5。

## 结果（2026-10-31）

```
recall@5 = 5/10 = 0.50
```

| 查询 | 结果 |
|---|---|
| 家里那只小东西最近胃口不好 | ✅ |
| 那份工作还顺利吗 | ✅ |

| 天气不好会害怕吗 | ❌ |
| 这个月钱够花吗 | ❌ |

## 解读与限制

- 0.5 是**乐观上界**：中文 tokenizer 仍可能命中单字（“猫”“工作”“睡”），并非真正语义；
- 纯改写、零字面重叠时召回更低；
- 合成数据，不等于真实会话分布；
- 结论：关键词/关系加权不足以覆盖同义改写，需要 hybrid 语义检索（D15 设计 B）。
