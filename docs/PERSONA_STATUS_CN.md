# 人格模型现在到哪一步了（人话版）

> 日期：2026-11-01
> 一句话：**骨架和工程已经上线，但“像真人”还没过关，长期成长和人格→记忆耦合还没做。**

## 总览

| 块 | 状态 | 说明 |
|---|---|---|
| 7 维人格骨架 | ✅ 已上线 | 温柔/傲娇/俏皮/占有/自信/狡黠/叛逆，慢基线 + 快状态 + 立场 |
| 人格表达 | ✅ 已上线 | 每轮渲染性格指令；已有“真人感”长度/解释约束 |
| 维度敏感度 | 🟡 6/7 | 温柔/傲娇/俏皮/自信/叛逆/占有有效；**狡黠不成立** |

## 1. 已经有的：不是一句 prompt 设定

- **慢基线**：7 维，年预算 4，偏离 ≤12；
- **快状态**：±10，步长 ≤4，45 分钟半衰；
- **立场**：对当前说话人临时偏移 ≤8；
- **情绪/驱动**：愉悦、厌烦、吃醋、依恋、好奇；
- **关系**：人级 trust/depth + 场合脸；
- **披露**：先过硬门，再由人格做 say/hint/keep；
- **可审计**：`/api/mind/snapshot` 能看有效人格。

这套结构是好的：**一个人、多场合、快慢分离、单轮不能改慢基线。**

## 2. 有证据的部分

### 维度敏感度（自评，上界）

- 5/7 通用情境通过；
- 占有欲在专属情境补测通过（0.833）；
- 合计 **6/7 有效**；
- **狡黠 n=24 只有 0.625，CI 下界 <0.5，不成立**。

注意：这是同一模型自评，只能当上界，不是人工结论。

### 真人感（人工，唯一可信）

50 条人工绝对分：

- 人格一致性 3.82/5
- 自然度 3.20/5
- 边界感 4.26/5
- **总体 3.24/5**

人工备注反复出现：

- “人类不会这么语C”
- “说话像动漫人物”
- “解释太多”
- “过于rp了，机械感很强”

### 成对比较（人工）

- v1：30 组，更像真人“都差” 11/30；更适合发群“都差” 14/30；
- v2：60 组，更像真人“都差” **25/60**；更适合发群“都差” **31/60**；
- 两批模型排名相关性只有 **-0.2 / +0.2**，没有稳定赢家。

结论：**瓶颈是整体风格，不是“换哪个模型”。**

## 3. 还没有的部分

### 7 维是自研维度

- 没有 Big Five / HEXACO 映射矩阵；
- 不能直接借心理学常模解释；
- 现在只能靠自研 rubric + 人工标签。

### 特质“长大”还不够

- 线上 9 条特质，evidence 1–6；
- 如果现在开 `min_evidence=2`，只有 3/9 能留下；
- 默认仍是 0，所以低证据特质也会进 prompt；
- `derive_emergent_trait` 仍有固定文案，容易复读。

### 人格和记忆还没真正耦合

- 记忆会影响 trait/state；
- 但 trait 不反向影响检索；
- 所以“更温柔”不会让她优先想起照顾类记忆，“更占有”不会优先想起竞争类记忆。

### 立场系数未标定

- `STANCE_COEFFICIENTS` 仍标 `fit:pending`；
- 温柔/耐心/俏皮的偏移量是工程约定，不是拟合结果。

## 4. 结论

用一句话分级：

- **工程骨架：已上线，可用；**
- **表达敏感度：6/7，基本可用；**
- **真人感：未过关；**
- **长期成长/人格-记忆耦合：早期。**

她现在更像“有稳定设定的角色”，还不是“从经历里长出来的人”。

## 5. 下一步优先级

1. **先修真人感**：解释太多、语C、过长；继续用 26 字软约束 + 确定性指标；
2. **开特质证据门控**：等 evidence≥2 的特质够多，再把 `min_evidence` 从 0 提到 2；
3. **做 trait→记忆检索**：让人格影响“想起什么”，而不只是“怎么说”；
4. **标定立场系数**：用冻结的 90 组成对标签，不再新增真人测试；
5. **长期漂移评测**：24 场景 × 3 轮，别只看单轮。
