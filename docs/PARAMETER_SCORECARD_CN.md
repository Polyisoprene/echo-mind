# 参数红绿灯（人话版）

> 一句话：**大部分数值现在有依据了，但系统效果还不够好。**
> 内部 70 条全过，不代表外部好用；LongMemEval 外部只有 51%。

## 先看 5 个结论

| 看什么 | 现在 | 怎么理解 |
|---|---|---|
| 内部评测 | **70/70** | 我们自己的 70 条固定题全过；题偏简单，不能当真实水平 |
| 外部评测 | **51%**（session recall@5） | LongMemEval 100 题，bge-m3 后为 51% |
| 外部最差 | **29.4%** | 单会话“助手/偏好”类，仍最弱 |
| 外部最好 | **82.4%** | 知识更新/多会话类，最强 |
| 自动测试 | **321 passed** | 代码没坏，但测试不等于效果 |

---

## 绿灯：可以信，先别动

| 参数 | 值 | 为什么可以信 |
|---|---:|---|
| RRF 融合常数 | 60 | 论文 Cormack 2009 的常用值 |
| BM25 词频参数 | 1.2 / 0.75 | BM25 论文默认值 |
| PageRank 参数 | 0.85 / 100 / 1e-6 | NetworkX 默认值；HippoRAG 同思路 |
| 规则关系置信度 | 1.0 | 正则精确命中，没有“猜”的成分 |
| 风格长度 | 26 字 | 50 条人工高分回复最大 26 字；样本小但至少有数据 |
| 多语言 embedding | bge-m3 | 跨语言 cosine 0.899；LongMemEval 44%→51% |

**这些不要因为“感觉不好”随手改。**

---

## 黄灯：能用，但没证明最好

| 项目 | 现状 | 风险 |
|---|---|---|
| 7 个 ranker 等权 | BM25/向量/时间/方向/关系/置信度/锁定，权重一样 | 冲突时会互相稀释；留一消融只有 relations 是唯一必需 |
| 时间/方向关键词约束 | 70 条上 0 误触发 | 还是中文关键词规则，不是真正意图理解 |
| 关系图覆盖 | 49 节点 / 39 边 / 14 个连通分量 | 图太稀疏，PPR 也救不了没连上的记忆 |
| 外部评测 | 100/500 题，检索-only | 没测回答生成；单会话仍差 |

---

## 红灯：已经删掉/不要再用

| 旧东西 | 为什么删 |
|---|---|
| `3/6/5/4/6` 词面权重 | 拍脑袋，没有来源 |
| 30 天半衰期 | live 的 ranker 只看排序，指数衰减不影响排序 |
| `max_hops=2` | 真实图有 4 跳，2 跳覆盖不了；已改 PPR |
| 语义侧 0.25 / 0.5 | 和关键词侧重复计分，已删 |
| LLM judge 绝对分 | 和人工只有 QWK 0.097，不能当门禁 |
| 关系 confidence 0.8 | 无依据；精确规则改 1.0 |

## 效果差，差在哪？

### 外部 51% 说明什么

换上 `bge-m3` 后，44% → 51%，证明语言因素占一部分；  
但仍有一半左右没命中，说明**单会话事实检索**和 session 聚合还有问题，不是换个模型就结束。

### 单会话仍最差（29.4%–31.2%）

- single-session-user：31.2%
- single-session-assistant：29.4%
- single-session-preference：29.4%

说明“只出现过一次的用户事实”没有被稳定检索到。

### 知识更新/多会话最好（82.4%）

这两类文本线索更明显，BM25 + 时间排序 + bge-m3 都能帮上忙。

---

## 现在最值得做的 3 件事

1. **补单会话事实的检索**，这是外部最差项；
2. **扩到 500 题**，确认 51% 不是 100 题的偶然；
3. 再决定是否给 ranker 做拟合（目前仍不建议先调权重）。

**不要先做**：继续给 ranker 调权重。现有数据证明不了哪个权重更好。

---

## 一句话总结

- **参数本身**：大部分绿灯，少数黄灯，旧的红灯已删；
- **系统效果**：内部很漂亮，外部 51%；
- **下一步**：补单会话、扩样本，不是继续拍权重。
