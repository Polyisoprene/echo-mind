# 人格成对比较 v2（60 组新场景）结果

## 结论

**没有稳定的模型排名。** v1（30 组）与 v2（60 组新题）的模型胜率排序相关性只有 **-0.2（更像真人）/ +0.2（更适合发群）**，接近随机。模型之间的差异主要是题目批次噪声，不是稳定能力差异。

## v2 选择分布

- 更像真人：`都差` 25/60、`平局` 8、`A/B` 27；
- 更适合发群：`都差` 31/60、`平局` 3、`A/B` 26。

“都差”比 v1 更高（v1 为 11/30、14/30），说明整体风格仍未过“像真人”的线。

## 判断

1. **不要用 30/60 组选模型**；换一批题排名就翻转。
2. `都差` 占 42%–52%，瓶颈是**整体风格**，不是模型。
3. MiniMax 在 v2 决定性 0/9、0/8；但 v1 还有 0.4/0.25，仍需更多样本确认，不能直接判死。
4. 下一步应该是**改风格**，然后用同一批 v2 题复测，而不是继续换模型。
