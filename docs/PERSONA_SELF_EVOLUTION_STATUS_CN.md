# 人格自演化：现在到哪一步

> 一句话：**已经在演化，但演化是“有界漂移 + 固定模板”，还没形成闭环。**

## 1. 现在真在演化的部分

一轮对话结束后：

```
行为结果 → 快状态（±10，45min 半衰）
        → 待结算观测
        → 日结算：慢基线（年预算 4，偏离≤12）
        + 涌现特质（evidence/strength）
        + 关系/记忆更新
```

- **慢基线**：7 维，每天最多推一点，全年最多 4 点，偏离不超过 12；
- **快状态**：每轮变，但会衰减；
- **特质**：会累计 evidence、strength；
- **关系/记忆**：会随互动更新。

所以不是“不会变”，而是**变得很慢、有上限**。

## 2. 影响自演化的缺口

| 缺口 | 对自演化的影响 | 严重度 |
|---|---|---:|
| `min_evidence=0`，特质证据门控没开 | 低证据特质也会进 prompt；演化没有“淘汰”，噪声会积累 | 高 |
| `derive_emergent_trait` 只有 5 条固定文案 | 经历再新，也只能长成这 5 句话；成长会平台化 | 高 |
| 人格→记忆检索没做 | 变温柔不会优先想起照顾类记忆；演化不会通过记忆复利 | 高 |
| 立场系数 `fit:pending` | 对不同人的偏移是手调的，不会从互动里学 | 中 |
| 没有长期漂移 benchmark | 看不出演化是“成长”还是“跑偏/振荡” | 高 |
| 7 维无 Big Five/HEXACO 映射 | 不影响机制，但没法借心理学常模判断是否健康 | 中 |
| judge 不可信 | 只影响评测，不影响演化机制 | 中 |

## 3. 最关键的一句

**演化本身在跑，但“选择压力”和“复利”没接上。**

- 没有 evidence 门控 → 什么经历都留下，不会淘汰；
- 没有 trait→memory → 人格变化不会改变她“想起什么”，只改变“怎么说”；
- 没有长期漂移评测 → 不知道一年后是更立体，还是变成怪癖集合。

结果就是：**会漂，但不一定会长成更好的人。**

## 4. 这算不算“自演化”

按现在的实现，准确说法是：

> **有界人格漂移（bounded adaptation）**，不是开放式自演化。

它不会：
- 自己改代码/改 prompt 结构；
- 自己生成全新价值观；
- 自己决定“我要变成什么样”。

它会：
- 根据互动慢慢挪 7 维；
- 累计习惯/雷点；
- 改关系、改记忆权重。

## 5. 优先级

1. **开特质证据门控**：等 evidence≥2 的特质够多，把 `min_evidence` 从 0 提到 2；
2. **做 trait→记忆检索**：让人格影响“想起什么”；
3. **换掉固定 5 条文案**：改成从证据生成的 trait 模板；
4. **长期漂移评测**：24 场景 × 3 轮，先能测，再谈调；
5. **标定立场系数**：用冻结标签，不再新增真人测试。

## 结论

- 自演化：**有，但很浅、很慢、有界**；
- 影响最大的不是“7 维准不准”，而是 **证据门控、trait→memory、长期漂移评测**；
- 在没接上这三件事之前，她更像“会缓慢变化的角色”，还不是“会从经历里长出来的人”。
