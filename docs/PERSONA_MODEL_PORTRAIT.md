# 人格模型全景画像

> 日期：2026-10-31。对象：EchoMind 当前线上人格（`main@911c1f7` + 披露模型设计）。
> 目的：让你在一张图里看清“她由哪些部分组成、每部分干什么、彼此怎么连”。

---

## 0. 一句话

她是一个**单一的、连续的、受关系调制的人格**：
**慢基线（7 维，年年微调）→ 快状态（±10，45 分钟半衰）→ 对当前人的立场（±8）→ 情绪与驱动（分钟级）**
共同渲染成每轮 prompt 里的一段“性格指令”；她的行为结果再通过塑性引擎回流，但**单轮永远不能改慢基线**。

## 3. 一轮对话的数据流

1. **感知**：`evaluate_incoming` → 唤醒/静默；用 `talkativeness`、`skepticism`、`curiosity_rate`。
2. **组装 frame**（`facade.build_cognitive_frame`）：
   1. 读**全局** working state（情绪/驱动）；
   2. 读本群事实、人物档案、程序规则；
   3. 算关系深度、和弦、影子评估（性格→厌烦/逆反）；
   4. `effective_params = 基线 + 快状态`，再 `apply_stance(当前说话人)`；
   5. 用有效参数 + 涌现特质渲染**性格指令**；
   6. 召回往事（艾宾浩斯加权）、好奇问题、禁令；
   7. 拼成 `rendered_mind_block` + 性格块 + 控制论核心。
3. **提示词**：`runtime/prompt_composer.py`
   - system：身份 + 认知层级说明 + 表情包 + 语音指南；
   - user：已读上下文 + **mind block（含性格块）** + 时间断层 + 回复提醒 + 最新消息。
4. **生成**：LLM 调用工具/输出文本。
5. **回流**：`on_turn_completed` → `compute_param_deltas`（行为 + 人格）→ 快状态 + 待结算；关系/记忆/特质更新。
6. **结算**：每天一次，把待结算观测折进基线（≤4），并做慢回归。
7. **观察**：控制台读**有效参数**（基线+状态），不是基线本身。

## 4. 7 维：每一维控制什么

| 维度 | 范围/默认 | 当前基线 | rubric 高档/中档阈值 | 立场系数 | 披露角色（计划） | 审计状态 |
|---|---|---|---|---|---|---|
| 温柔 `warmth` | 15–98 / 65 | 65.0 | 72 / 48 | +1.0 温柔 | 保护当事人，少伤人八卦 | 极端 0.750 |
| 傲娇 `tsundere` | 10–95 / 62 | 62.0 | 68 / 48 | −0.8 温柔 | 暗示而非直说 | 极端 0.750 |
| 俏皮 `playfulness` | 15–95 / 58 | 58.0 | 65 / 45 | +1.0 俏皮 | 把趣事当社交货币 | 极端 0.750 |
| 占有欲 `possessiveness` | 20–98 / 75 | 75.0 | 75 / 52 | — | 对竞争者相关记忆追问/保留 | 专属情境 0.833 |
| 自信 `confidence` | 15–95 / 55 | 55.0 | 65 / 42 | +0.2 俏皮 | 直接度 | 极端 0.896 |
| 狡黠 `guile` | 10–95 / 52 | 52.0 | 58 / 40 | — | 策略性暗示、留余地 | R=3 0.708 |
| 叛逆 `defiance` | 10–95 / 48 | 48.0 | 58 / 40 | −0.7 耐心 | 敢破场面规矩（硬门内） | 极端 0.833 |

**读法**：rubric 档位决定“她在 prompt 里读到哪一档的语气示例”；立场系数决定“面对不同关系的人，哪几维临时偏移”；披露角色是设计中的新任务，尚未上线。

## 6. 五条反馈回路

1. **情绪回路（秒–分钟）**：愉悦向 62 回归、吃醋 ×0.88 衰减、厌烦阈值触发冷肩。
2. **快状态回路（分钟–小时）**：每轮观测 ±4，45 分钟减半；决定“今天她是不是更黏/更冲”。
3. **慢基线回路（天–年）**：日结算 ≤4，向默认回归 0.11%/天（半衰期约 624 天）。
4. **关系回路（天–月）**：信任/深度/背叛；背叛走 `W_BETRAY` 抑制深度。
5. **记忆回路（天）**：整合成情节/事实/规则；召回按艾宾浩斯强化。

**关键约束**：1–2 是“此刻”，3 是“她这一年”，4–5 是“她和你/这个群的历史”。三者不能互相越权。

## 7. 她每轮“看到”的世界

**Mind block（user 消息内）**，按渲染顺序：

1. 头部：北京时间 / 场景 / 正在做 / 精力 / 愉悦·厌烦·吃醋 / 依恋·好奇 / 心结；
2. 在场群友档案（≤16 人：关系、等级、信任）；
3. 权威事实（≤28 条：置信度、锁定/待核实）；
4. 禁令（banned phrases）；
5. 认知警报 + 影子评估指令 + 匹配到的程序规则；
6. 海马体召回往事（艾宾浩斯加权）；
7. 好奇问题；
8. **性格指令块**（7 维 rubric + 依恋类型 + 腔调）+ **控制论核心**（序参量/工具/温度）。

**System**：身份 + 认知层级 + 表情包 + 语音指南。

## 9. 已知缺口与边界

| 缺口 | 现状 | 影响 |
|---|---|---|
| **没有来源/受众/披露层** | 召回内容直接进 prompt | 她不知道“这话是从哪听的、在场的人该不该知道” |
| **涌现特质是 5 条固定文案** | `derive_emergent_trait` 条件命中固定文本 | “成长”有限，容易重复 |
| **HEXACO 命名** | 指令里写 HEXACO & 2D Attachment | 实际只用了 7 维 + 依恋四型，名不副实 |
| **审计只覆盖风格** | 极端档 / ±10 / ±15 | 不覆盖“说不说、对谁说” |
| **性格块在 user 消息** | `prompt_composer` | 服从度可能低于 system（A3 待验证） |
| **渲染缓存单槽** | `persona_render._CACHE` | 多群并发时命中率低，非错误 |
| **情绪全局** | 单 `global` working state | A 群的情绪带到 B 群（人味，但需被披露层理解） |

## 10. 披露层插在哪

```
facts + recalled
      │
      ▼
DisclosurePlanner（新）
  输入：候选记忆（来源/归属/敏感度/受众）
      + 当前受众（在场人/关系/场所）
      + 有效人格（基线+状态+立场）
      + 情绪/驱动
  输出：included（带来源/措辞） / withheld / ask / deflect
      │
      ▼
mind block 只渲染 included → prompt
      │
      ▼
DisclosureLog + knowledge_state 更新
      │
      ▼
行为结果 → 现有塑性引擎（不新建）
```

**它消费**：7 维、快状态、立场、情绪、关系、记忆来源。
**它生产**：筛选后的记忆、来源标注、告知史、披露日志。
**它不碰**：E2 节奏、硬门之外的评分、bond 公式。

## 11. 控制面板：你能改什么

| 想改 | 怎么改 | 边界 |
|---|---|---|
| 她“本来是谁” | 控制台调 `plastic_params`，或重置脚本 | 慢基线；E2 上限仍生效 |
| 她“现在什么心情” | 事件/互动自然驱动；控制台可改 working state | 分钟级会衰减 |
| 对某个人的态度 | 改 `social_bonds`（好感/信任/深度） | 立场 ≤8 |
| 说话风格 | 7 维 rubric（`persona_rubrics.py`） | 改文案即改表达 |
| 行为习惯 | 5 个行为参数 | 已纳入两层引擎 |
| 身份/人设 | persona card（botName/roleText） | 不自动改 7 维 |
| 学习速度 | E2 常数（4/年、4/天、±10/45min） | 改常数需重新审计 |
| 硬边界 | 披露层硬门（待建） | 不可被性格绕过 |

**看不到/改不了的**：慢基线为什么是这个值（只有结算日志）、快状态为什么偏移（只有 `persona_state` 当前值）、披露决策为什么（待建日志）。

## 12. 一句话收束

**慢基线是“她是谁”，快状态是“她今天怎样”，立场是“她对你怎样”，情绪/驱动是“她此刻怎样”，
记忆/关系是“她经历了什么”，rubric/提示词是“她怎么表达”，塑性/结算是“她怎么变”。**

披露层要做的，是在“她怎么表达”之前加一道**社会判断**：
这条记忆从哪来、在场的是谁、该不该说、怎么说。
它不改“她是谁”，只改“她说不说”。
