# 真人感风格修正（基于已冻结的人工标签）

> **2026-11-01 状态**：本文是历史人工标签分析；当前确定性风格指标与 API 见 [PERSONA_STYLE_MONITORING.md](PERSONA_STYLE_MONITORING.md) 与 [CURRENT_STATE_2026-11-01.md](CURRENT_STATE_2026-11-01.md)。

> 不再新增真人测试。以下规则只从已有 50 条人工标签和 90 组成对比较中提炼，之后用确定性指标监控。

## 从 50 条标签里看到的

按回复特征分组，比较人工“总体”均分：

| 特征 | 条数 | 该组均分 | 其余均分 |
|---|---:|---:|---:|
| 长度 > 40 字 | 3 | 2.33 | 3.30 |
| 出现解释词（因为/所以/不能/隐私/规则/需要/建议） | 2 | 2.00 | 3.29 |
| 有括号动作 | 3 | 3.33 | 3.23 |
| 多个问句 | 4 | 3.75 | 3.20 |
| 波浪号 | 1 | 2.00 | 3.27 |

小样本，不能当因果；但和人工备注一致：

- “解释太多”
- “人类不会这么语C”
- “说话像动漫人物”
- “过于rp了”

括号动作、多问句**没有**被稳定扣分，所以不搞一刀切禁用。

## 采用的规则

1. 默认 **1–2 句、尽量 ≤26 字**；
2. 先接话/接情绪，**不解释人设和规则**；
3. 拒绝/边界**只回一句**；
4. 不客服腔、不语C、不加括号动作；
5. 只有对方明确需要详细说明时才展开。

## 改动位置

`synthesize_live_persona_directive()` 末尾新增：

```
【真人感硬约束】默认 1–2 句、尽量不超过 26 字；先接话/接情绪，
不解释人设和规则；拒绝或边界只回一句；不要客服腔、语C、括号动作；
只有对方明确需要详细说明时才展开。
```

这是**软约束**，不截断回复；技术/安慰类需要长回答时仍可展开。

## 监控（不再真人测试）

以后只看确定性指标，不让你再标：

- 平均回复长度、>40 字比例；
- 解释词命中率；
- 括号动作/语C 标记命中率；
- 多问句比例；
- 边界场景是否仍然拒绝。

目标：长度和解释率下降，隐私/边界不退化。

## 边界

- 规则来自 50 条小样本，不是 universal；
- 如果线上出现“太短、接不住情绪”，优先放宽长度，不放弃边界；
- 不再用绝对分 judge 做门禁。
