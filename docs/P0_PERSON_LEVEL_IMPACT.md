# P0 影响建模：关系归人之后，她实际会怎么变

> 数据：现网 41 条关系、30 个有统计的人（`data/echomind.db`，2026-10-31）。
> 方法：`scripts/person_level_impact.py`（只读）。对比“现状 per-venue”与“人级 trust + 人级绝对深度（全局分位）”两套映射。

---

## 一、映射规则

**现状**

```
warmth   = tanh(stored_depth/100 × 1.6)      # stored = 组内排名混合值
patience = tanh((venue_trust − 0.5) × 2)
play     = tanh((venue_affinity − 50)/50)
```

**人级**

```
trust_person  = 按消息量加权的跨场合信任
depth_person  = 跨场合汇总统计 → depth_from_stats → 全局百分位（0–100）
warmth   = tanh(depth_person/100 × 1.6)      # 同一个人→同值
patience = tanh((trust_person − 0.5) × 2)    # 同一个人→同值
play     = tanh((venue_affinity − 50)/50)    # 保留场合差异
```

立场差 × `STANCE_MAX_POINTS=8` 换算成 7 维上的点数。

## 五、建模暴露的一个真 bug：私聊里 care = 0

`care_weight(affinity, trust, depth)` 的公式：

```
base = clamp((affinity − 38)/70) × trust
bonus = 1 + 0.35 × depth/100
```

你在私聊的好感是 **32.1**，低于 `AFFINITY_OFFSET=38` → `base=0` →
**私聊里她对你的 care 权重是 0**，尽管信任 0.78、深度 50.7。

这不是“关系冷淡”，是**公式的截断**：`AFFINITY_OFFSET/SPAN` 是 `convention:legacy-w-care`
（旧映射，没有数据支撑）。好感一旦低于 38，care 直接归零。

**修复方向**（二选一，或并用）：

1. care 改用**人级好感**（跨场合加权，你约 47.5），而不是场合好感；
2. 用现网好感分布重标定 `AFFINITY_OFFSET/SPAN`（E1 式：P5/P95 + CI），不要再用 38/70。

推荐 1 + 2：care 归人（关心是人对人的），play 归场合（玩笑是场合的）。

## 八、建议的 P0 范围（修正版）

1. 新增 `depth_absolute`（人级，全局分位）与 `venue_rank`（场合）；
2. `persona_stance`：温柔/耐心读人级，俏皮读场合；
3. **`care_weight` 改用人级好感**，并用现网分布重标定 `AFFINITY_OFFSET/SPAN`；
4. 加三条测试：
   - 同一人跨场合温柔/耐心差 ≤2；
   - 你本人在私聊的 care > 0；
   - 被组内排名归零的人，改后温柔上升且不超过 +7。
5. dry-run 对照 41 条关系的旧/新 stance 与 care，逐条可解释。

## 九、一句话

**关系归人不会让她“变个人”，只会让她对“群里最不活跃的那几个人”不再像陌生人；
同时它暴露了一个更实际的 bug——你在私聊里的 care 权重是 0，因为好感低于旧公式的截断线。**
